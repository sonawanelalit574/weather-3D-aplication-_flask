# 🌍 3D Weather Earth

A modern Flask weather application with an interactive 3D Earth.

## Features

- 🌍 Interactive 3D Earth
- 🛰️ Satellite mode
- 🗺️ Hybrid mode
- 🔎 Country + City search
- 📍 Fly to searched location
- 🌡️ Current temperature
- 🌡️ Feels-like temperature
- 💧 Humidity
- 💨 Wind
- ☁️ Cloud percentage
- 🌧️ Rain probability
- ☀️ UV index
- 👁️ Visibility
- 📅 7-day forecast
- 🕐 24-hour forecast
- 💡 Smart weather insights
- 🛡️ Safety precautions
- ☀️ Summer protection
- 🌧️ Heavy rain protection
- ❄️ Winter protection
- ⛈️ Thunderstorm protection
- 🌫️ Fog protection

## Technologies

- Python
- Flask
- JavaScript
- HTML5
- CSS3
- Google Maps Platform 3D Maps
- Open-Meteo API
